Elastic Network Model (ANM) for GPCR Activation

Run GPCR-ANM

You can perform a guided ANM analysis on your own pair of structures. Simply upload two PDB files below: the reference inactive structure and the corresponding active structure. The server will align the structures, compute distance‑dependent spring constants, build the Hessian, and perform a normal mode analysis. Two files will be returned for download: *_inactive.pdb (a copy of your inactive structure) and *_transition.nmd (which can be uploaded in VMD/Extensions/Analysis/Normal Mode Wizard/Load NMD File) to observe the motions corresponsing to each modes.



Run Conventional ANM

Upload a single PDB file to run a conventional ANM using ProDy. The server will build the Hessian and compute normal modes. You will receive a ZIP containing initial_structure.pdb and conventionalANM.nmd for visualization in VMD (Normal Mode Wizard).


Overview

This website illustrates the application of a state-dependent Elastic Network Model to study the conformational transition of G-Protein Coupled Receptors (GPCRs) from an inactive to an active state. Unlike standard ANM approaches that use a universal spring constant, our guided ANM uses distance-dependent force constants to soften specific interactions that change significantly during activation.

The implementation here uses PDB structures 2rh1 (inactive) and 3sn6 (active), aligns them using ProDy, and computes pairwise distance changes between corresponding Cα atoms. Contacts that increase or decrease by more than a threshold (2 Å) during activation have their spring constants exponentially softened. This results in a Hessian matrix that captures state-aware physics for the receptor's transition.

Methodology

The guided ANM computation follows these steps:

  1. PDB Parsing: Extract Cα atom coordinates from the inactive and active structures.
  2. Alignment: Align the active structure onto the inactive one using ProDy (Kabsch algorithm) to minimize root-mean-square deviation.
  3. Distance Changes: Compute pairwise Cα distances in both states and record the difference Δr = r_active − r_inactive for contacts within a 15 Å cutoff.
  4. Force Constant Softening: For contacts with |Δr| > 2 Å, set the spring constant γij = 0.1 · exp(−|Δr| / 5). All other contacts use γij = 1.
  5. Hessian Construction: Build the 3N×3N Hessian matrix by assembling 3×3 blocks based on the unit vector between residues and the force constants.
  6. Normal Mode Analysis: Solve the eigenvalue problem to obtain normal modes. The lowest non-zero modes represent the collective motions involved in the transition.
